# Awaaz Shield API reference

Base URL: `https://awaaz-shield.onrender.com` (locally `http://127.0.0.1:8000`). Interactive, always-current docs are generated by FastAPI at `/docs` (Swagger) and `/openapi.json`. This page adds what those do not show: the WebSocket protocols and the rules behind the routes.

**Authentication.** Every route except `/api/health` and `/api/status` needs the session cookie set by `POST /api/auth/session` (or `/api/auth/dev-login` in local development). WebSockets use the same cookie; without it they close with code `4401`. A call is visible only to its owner, to people who joined its voice room, and (if it was escalated) to operators listed in `OPERATOR_EMAILS`. Anyone else gets `404`, not `403`.

## Health and status
| Method and path | Purpose |
|---|---|
| `GET /api/health` | `{"ok": true}`. No sign-in. Used by the keep-awake ping. |
| `GET /api/status` | No sign-in. Which services are configured (Deepgram, Firebase, Claude), the auto-end settings, the consent version. |

## Auth: `/api/auth`
| Method and path | Body | Returns |
|---|---|---|
| `POST /session` | `{id_token}` (Firebase ID token) | Sets the session cookie. `{uid, email, dev_mode}` |
| `POST /dev-login` | `{email}` | Local development only (when Firebase is off). Same result. |
| `GET /me` | none | `{uid, email, dev_mode, operator}` |
| `POST /logout` | none | Clears the cookie. |

## Consent: `/api/consent`
| Method and path | Body | Returns |
|---|---|---|
| `GET` | none | `{required_version, accepted, at, source}` |
| `POST` | `{version, language}` | Stores the acceptance in Firestore and a local file. `{accepted, stored: [...]}` |

## Calls: `/api/calls`
| Method and path | Body | Returns |
|---|---|---|
| `POST ""` | `{label?, source?}` | A new `Call` |
| `GET ""` | none | The calls this person may see |
| `GET /{id}` | none | One `Call` |
| `POST /{id}/ingest` | `{text, speaker}` (`caller`, `agent`, `unknown`) | The scored `Call`. Adds a transcript line, rescores, broadcasts. |
| `POST /{id}/end` | none | The ended `Call` |
| `POST /{id}/actions` | `{type, note?}` (`flagged`, `escalated`, `dismissed`, `restored`, `note`) | The recorded action. `escalated` shares the call with operators, permanently. |
| `POST /{id}/evaluate` | `{message}` (1 to 2000 chars) | Risk-evaluator answer: `{score, level, basis, answer, explanation, warning_signs, recommended_steps, ...}`. Rate limited per person. Nothing is stored. |
| `DELETE /{id}` | none | Permanently deletes an ended call. Owner only. `409` if still active. |
| `DELETE ""` | none | Deletes every ended call this person started. `{deleted, skipped_active}` |

`Call` fields: `id, label, source, status, started_at, ended_at, transcript[], risk_history[], alerts[], actions[], current_score (0-100), current_level (low | medium | high | critical), last_explanation, scorer, signals[], ended_reason ("auto_risk" when the app cut it), ended_threshold, shared_with_operators`.

## Analytics and demo
| Method and path | Purpose |
|---|---|
| `GET /api/analytics` | Counts and score trends for this person's calls. |
| `POST /api/demo/patterns` | `{category, phrase, weight, language}`: add a scam phrase live. |
| `POST /api/demo/reset` | Clears the demo data. |

## In-app voice calls
| Method and path | Purpose |
|---|---|
| `POST /api/voice/calls` | `{label?}` returns `{call_id, code, label}`. The six-character code is read out to the other person. |
| `GET /api/voice/rooms/{code}` | Room state: `host_present`, `guest_present`, `is_host`. `404` if the code expired. |

### `WS /ws/voice/{code}`
The browser sends one JSON text message `{"type":"ack_notice"}` once the person accepts the "this call is relayed and analysed" notice, then binary frames of raw PCM16, mono, 16 kHz (20 ms each; frames over 16,000 bytes are rejected). **Nothing is relayed or transcribed until both people have accepted.** The host is the scored side (`caller`); the guest is the `agent`.

Messages from the server (JSON text):

| `type` | Fields | Meaning |
|---|---|---|
| `joined` | `role, code, call_id, label, peer, stt` | You are in the room. |
| `peer` | `state` (`joined` or `left`) | The other person arrived or left. |
| `live` | | Both accepted: audio now flows. |
| `peer_muted` | `muted` | |
| `caption` | `speaker, text, final` | A transcript line, partial or final. |
| `risk` | `score, level` | After every finished phrase. |
| `warning` | `score, limit` | The caller's score is over the limit. If they keep saying suspicious things, the call will be cut. |
| `notice` | `code, message` | E.g. `stt_unavailable`: the call works but is not transcribed. |
| `ended` | `reason` (`host_left`, `risk_threshold`), `score, limit` | The call is over. The socket then closes. |
| `error` | `code, message` | The socket then closes. |

Binary frames from the server are the other person's audio.

**Auto-cut rule.** When the caller's cumulative score rises above `AUTO_END_SCORE` (default 75, `0` turns it off), both people get a `warning`. The call is cut only after `AUTO_END_LINES` (default 2) caller lines in a row stay above the limit and, from the second on, each matches a scam pattern. A score at or below the limit resets the count. The call is then ended, marked `ended_reason: "auto_risk"`, and escalated to operators.

### `WS /ws/stt/{call_id}?speaker=caller&diarize=0&lang=`
Streams one microphone to Deepgram for a single call (live dashboard use, e.g. a speakerphone call). The browser sends binary PCM16 frames; the server sends transcript and score updates and an `error` message with `code: "not_configured"` if `DEEPGRAM_API_KEY` is empty. The Deepgram key never reaches the browser.

### `WS /ws/dashboard`
One broadcast channel. Each event is filtered so you only receive events about calls you may see. Events: `call_created`, `call_updated`, `alert`, `action_recorded`, `auto_ended` (operators), `demo_reset`.

## Errors
`401` no or expired session; `404` not found or not yours; `409` call still active; `429` evaluator rate limit; `503` storage unavailable (nothing was changed).
